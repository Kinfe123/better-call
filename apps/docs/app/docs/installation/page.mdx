# Installation

Install Better Call in the host application first, then continue to the usage and concept pages for the first real integration.
```bash
pnpm i better-call
```

Make sure to install [standard schema](https://github.com/standard-schema/standard-schema) compatible validation library like zod.

```bash
pnpm i zod
```
